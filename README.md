# Laboratorio de Ingeniería de Software

## Descripción
Proyecto desarrollado para practicar el uso de Git y GitHub como herramientas de control de versiones en proyectos de software.

## Objetivos
- Configurar un entorno de desarrollo
- Aprender el uso básico de Git
- Gestionar repositorios locales y remotos
- Realizar commits y sincronización con GitHub

## Herramientas Utilizadas
- Git
- GitHub
- Visual Studio Code
- Git Bash
- Python
